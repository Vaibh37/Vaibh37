## About

I build things for the web.

My current focus is **full-stack development with MERN**, while gradually exploring **AI, modern backend systems, databases, and better product architecture**.

I care more about turning an idea into something usable than collecting technologies for a list.

Most of my learning happens where it matters:

```text
idea → build → break → debug → understand → improve → ship
```

## How I Build

I don't want my GitHub to become a collection of abandoned tutorials.

I want every project to teach me something the previous one didn't.

```text
01. Understand the problem
02. Build the simplest working version
03. Find what breaks
04. Understand why it broke
05. Improve the architecture
06. Refine the experience
07. Ship
08. Repeat
```
