## About Me

<img
src="./assets/console.svg"
width="100%"
alt="Developer Console"
/>

<br/>

I'm focused on **full-stack web development**, primarily around the **MERN ecosystem**, while expanding into modern frontend frameworks, databases and AI-enabled applications.

I work across the complete application flow:

**UI → Frontend Logic → APIs → Authentication → Backend → Database → Deployment**

My current goal is to become stronger at building complete, production-style applications instead of only isolated frontend projects.

## Development Areas

### Frontend Development

Building responsive interfaces and learning how modern frontend applications are structured.

`HTML` `CSS` `JavaScript` `React` `Next.js`

<br/>

### Backend Development

Working with server-side JavaScript, API design, authentication and application logic.

`Node.js` `Express.js` `REST APIs` `Authentication`

<br/>

### Databases

Exploring relational and document databases along with caching systems.

`MongoDB` `PostgreSQL` `MySQL` `Redis`

<br/>

### AI Integration

Exploring how AI can be integrated into real web products rather than existing only as isolated demos.

`LLM APIs` `AI Features` `Automation` `Product Integration`
